Learning-focused ecommerce application demonstrating:

- React
- Node.js
- Express
- Microservices
- API Gateway
- MySQL
- Redis
- Kafka
- Redis Pub/Sub
- WebSockets
- Docker
- Event-driven architecture
- Asynchronous communication
- Inventory reservation and TTL
- Eventual consistency
